# Mods

This folder contains all the mods for the game for your new HTML build. Each mod should have its own subfolder with the necessary assets and configuration files.

Structure of this Directory:
```markdown
example_mods/
├── characters
│   ├── music
│   ├── sounds
│   ├── images
│   ├── custom_notetypes
│   ├── custom_events
│   ├── data
│   ├── fonts
│   ├── videos
│   ├── pack.json
│   ├── pack.png
```
